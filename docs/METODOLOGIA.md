# Metodologia

Base: `plano-estoque-facil.md`. Documento local, não versionado.

## Dinâmica

Encontros previstos para quintas-feiras, usando VS Code e Live Share. O aluno conduz a maior parte da programação e explica seu raciocínio. O instrutor acompanha, faz perguntas, revisa e demonstra exemplos curtos quando necessário.

## Roteiro de cada encontro

1. Retomar o aprendizado anterior com uma pequena alteração.
2. Escolher uma entrega e ler somente a etapa correspondente de `PLANO.md`.
3. Descrever a solução em português e escrever uma tentativa à mão.
4. Executar, experimentar entradas válidas e inválidas e corrigir.
5. Solicitar revisão da IA e discutir as sugestões.
6. Explicar e adaptar o código, registrar dúvidas em `ENCONTROS.md` e fazer um commit do trabalho pertinente.

## Uso de IA

Usar IA para planejamento, explicações, pistas e revisão. Explicitar a etapa atual e a dúvida. Conferir as sugestões executando o código e relacionando cada mudança ao comportamento esperado. Evitar avançar para abstrações que o aluno ainda não consegue explicar.

As instruções essenciais para agentes ficam no `AGENTS.md` da raiz, que será versionado e poderá evoluir durante o aprendizado.

## Revisão e Git

- Revisar a entrega acordada, a clareza do código e o tratamento das entradas relevantes.
- Usar Git desde o início, com mudanças pequenas e mensagens que expliquem o propósito do commit.
- Introduzir branches e Pull Requests gradualmente, conforme a compreensão.
- Conferir o diff e os arquivos preparados antes de cada commit.
- Manter `docs/` fora do versionamento. Compartilhar esses registros separadamente quando necessário para os encontros.
- Atualizar o README com funcionalidades disponíveis e execução conforme o projeto evoluir.

## Critério para avançar

Avançar quando a entrega funcionar e o aluno conseguir explicar e adaptar a solução. Registrar dificuldades e retomar os conceitos necessários, sem impor uma etapa por encontro.
